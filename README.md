# Cristian Zúñiga Toledo · Fotografía

Sitio web de Cristian Zúñiga Toledo, fotógrafo y reportero gráfico en Las Terrenas, Samaná (República Dominicana).
*Arte, pasión y visión en cada imagen.*

Página estática en un solo archivo, bilingüe (ES / EN), con animaciones (GSAP, ScrollTrigger, Flip y Lenis, incluidos en `js/vendor/`).

## Estructura

- `index.html` — la página completa (HTML, CSS y JavaScript)
- `img/` — fotografías de Cristian
- `js/vendor/` — librerías de animación

## Ver en local

```bash
python3 -m http.server 8000
# abrir http://localhost:8000
```

## Publicar

Es un sitio estático: funciona en GitHub Pages (Settings → Pages → rama `main`, carpeta raíz), Netlify o cualquier hosting.
